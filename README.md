# 3D Portfolio Website

A modern, interactive 3D portfolio website built with Next.js, React Three Fiber, and TailwindCSS.

## 🚀 Tech Stack

### Frontend
- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript**
- **TailwindCSS 4**
- **React Three Fiber** (coming soon)
- **Framer Motion** (coming soon)

### Backend (Planned)
- **Node.js + Express**
- **MongoDB Atlas**
- **JWT Authentication**

### Deployment (Planned)
- **Vercel** (Frontend)
- **Render** (Backend)
- **MongoDB Atlas** (Database)

## 📦 Getting Started

Install dependencies:

    npm install

Run development server:

    npm run dev

Open http://localhost:3000 in your browser.

## 📂 Project Structure

    3d-portfolio/
    ├── app/              # Next.js App Router pages
    ├── public/           # Static assets
    ├── node_modules/     # Dependencies
    ├── package.json      # Project metadata
    ├── tsconfig.json     # TypeScript config
